Hypersnap Network Status

Live health of the Hypersnap network: every node reachable through the gossip mesh, its IP, version and sync state, each shard's latest block and validators, uptime history and incidents. Checked every minute.

Hypersnap is a community-run Farcaster network forked from Snapchain. This page walks the gossip mesh every minute through each node's public API (/v1/info, /v1/currentPeers). Nodes without a public API show up as seen in gossip.
