Hypersnap Network Status

Live health of the Hypersnap and Snapchain networks: every node reachable through the gossip mesh, its IP, version and sync state, each shard's latest block and validators, uptime history and incidents. Checked every minute.

Hypersnap is a community-run Farcaster network forked from Snapchain, and both still share one gossip mesh. Every minute this page walks that mesh through each node's public API (/v1/info, /v1/currentPeers) and tells the networks apart by /v1/nativeRegistration, which only Hypersnap serves. Nodes without a public API show up as gossip only.
